# Movie Data Analysis

## 项目介绍

这是一个使用 Python 进行电影数据分析的项目。

本项目通过对电影数据集进行探索性分析和可视化，
学习真实数据分析项目的完整流程。

## 使用工具
- Python
- pandas
- numpy
- matplotlib
- seaborn

## 项目结构

Movie-Data-Analysis/
│
├── data/          # 存放电影数据集
├── notebooks/     # 存放数据分析过程
└── src/           # 存放Python代码

## 分析目标
本项目希望通过电影数据分析，探索以下问题：

- 不同年份电影数量的变化趋势
- 不同电影类型的分布情况
- 电影评分与其他因素之间的关系
